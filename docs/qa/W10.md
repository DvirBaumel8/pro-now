# W10 — manual QA pass (docs/21 §6)

2026-09-30. WebKit at iPhone 15 size (393×852) and desktop Chromium, on the
**production build**: the API bundled by esbuild, `node dist/server.js`,
`NODE_ENV=production`, `ALLOW_LOCAL_STANDINS=1` against the compose
stand-ins (Postgres + PostGIS, Mailpit, SeaweedFS, the mock Google issuer).

## Findings

| # | What was tried | Result | Status |
|---|---|---|---|
| 1 | The whole e2e suite on the production build, first run | **33 of 43 failed**, in 10.8 min | Two causes, below |
| 2 | **WebKit: any screen** | **The app never started**: the page stayed at `/`, `dir="ltr"`. The production CSP had `upgrade-insecure-requests`, and Safari upgrades even `http://localhost`, so its own scripts were asked for over https | **Fixed**: HSTS and the upgrade only in production **and** when `PUBLIC_URL` is https; unit test for the http case |
| 3 | **Chromium: the 4th sign-in onwards** | **"לא הצלחנו לשלוח את הקישור"**. Better Auth's production limiter could not read one client address (no proxy header, or more than one address in it) and put everyone in one bucket: 3 sign-ins per 10 s for the whole site. On Render, with its proxy, the same could hit real users | **Fixed**: Fastify resolves the address (`TRUST_PROXY_HOPS`; Render measured at 3 after the deploy) and hands it to Better Auth in a header it overwrites; an integration test pins the address a session records, and that a client cannot name its own |
| 4 | The suite again, after both fixes | 42 passed, 1 skipped (the Nominatim contract test, which needs the network), 1.0 min | OK |
| 5 | The development-mode suite with the same changes | 42 passed, 1 skipped | OK |
| 6 | CSP violations walking `/welcome`, sign-in, the composer, `/addresses`, `/inbox`, `/pro/join`, `/` | 0, in both browsers | OK |
| 7 | `GET /api/ready` with storage stopped | 503, `storage: false`, no error text in the body | OK (integration) |
| 8 | Restore of a dump of the e2e database | 58 tables, 9,093 rows, 11 migrations, identical, 1.2 s | OK (`npm run drill:backup`) |
| 9 | Five professionals accepting one job at once, eight rounds | One winner each round; a control without `FOR UPDATE` fails | OK (integration) |
