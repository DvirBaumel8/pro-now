## Findings

| # | What was tried | Result | Status |
|---|---|---|---|
| 1 | Deep link to `/avatar` while signed out | Goes to `/welcome` | OK |
| 2 | Invalid email (`dana@`) | "שליחת קישור" is disabled | OK |
| 3 | **Double tap "שליחת קישור"** | **Two emails were sent**: `busy` only applies on the next render | **Fixed**: a synchronous in-flight guard. e2e regression test |
| 4 | **Browser/phone back on "בדקו את המייל"** | **Left sign-in for `/welcome`**; the demo's back returns to the field | **Fixed**: the sent stage is in the URL (`?sent=1`). e2e regression test |
| 5 | Reload mid-intro; back on the intro; visit `/` before finishing | Stays in the intro | OK |
| 6 | Signed in, visit `/welcome` or `/sign-in` | Goes home | OK |
| 7 | Go offline on home, then back online | The demo's banner ("אין חיבור לאינטרנט", "רענון"); on reconnect it refetches and clears | OK |
| 8 | Search "נזילה במטבח" | A suggestion appears, disabled as decided (W6) | OK |
| 9 | **`sw.js` 404 in WebKit** | The API had registered static files at boot, and the build finished after it | **Fixed**: files are served from disk as they are (no boot-time list) |
| 10 | **A very long email on "בדקו את המייל"** | **Ran off the screen, and the bidi was mangled** | **Fixed**: invisible break points after `@` and `.`. At a line break a dot may sit at the "wrong" end, as in any RTL text (cosmetic) |
| 11 | "נזילה במטבח" suggests **carpentry first** ("מטבח" matches kitchens), leak second | The shared keyword matcher, the same one the demo uses | **Deferred to W5** (understanding the request) |
