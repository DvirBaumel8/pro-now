# W7 — manual QA pass (docs/21 §6)

2026-09-30. **WebKit at iPhone 15 size (393×852)**, two browser contexts
(the professional and the customer), the production shape: the built app
served by the API on one origin, against a database of its own. Not a
real iPhone (see "Not verified").

## Findings

| # | What was tried | Result | Status |
|---|---|---|---|
| 1 | **Uploading a document from the browser** | **Every browser upload failed**: the PUT to the presigned storage URL was sent with credentials, which storage refuses. This covers the customer's photos and voice notes too (W4), which had never uploaded from a browser | **Fixed** (PR #10): `credentials: "omit"`, with a regression test. CI's e2e job got an S3 stand-in |
| 2 | Joining: welcome → sign-in → the application | Each step saves; the server lists what is missing; send is refused until nothing is | OK |
| 3 | Going online with location denied | "לא קיבלנו מיקום. כדי לקבל קריאות צריך לאשר גישה למיקום." | OK (`W7/01-online-location-denied.png`) |
| 4 | **The offer: "הסכום ייקבע במקום"** | **No expected earnings on any offer**: dispatch never wrote the payout snapshot | **Fixed**: from the professional's own price, marked "משוער" where it is an estimate (`W7/04-offer.png`) |
| 5 | **A professional who asked to be addressed in the feminine** | **The online screen and the offer spoke to her in the masculine** | **Fixed**: `proFemale` on the online screen and the offer's kicker. She is asked when joining (`addressAs`), never guessed |
| 6 | **"שיחה / הודעה" on the job, and "השיחה עוברת דרך מספר מסווה"** | **Buttons that did nothing**, and a claim about masked calls that do not exist | **Fixed**: shown only where calling or messaging exists (call masking is a §4 decision) |
| 7 | **The quote builder: "הלקוח יראה ויאשר"** | **False under D1**: the quote is approved on sending | **Fixed**: "באפליקציה לא עובר כסף — הסכום משולם לך ישירות" |
| 8 | Double tap on accept | One acceptance, no error | OK |
| 9 | Reload during "on the way" | Back at the same step, from the server | OK (`W7/06-en-route-after-reload.png`) |
| 10 | **Back from a finished job** | **Bounced straight back into the job**: the cached status still named it active | **Fixed**: the cached status is dropped before going back |
| 11 | The customer's name on the professional's job | Blank for customers with no name on file; the first name when there is one | Fixed to use the account's name; **a customer who never gave a name is shown as "הלקוח"** — asking for a name is a product question (the demo does not) |
| 12 | "הלקוח … הזמין את הקריאה" | The customer is addressed in the masculine: customers are not asked | **Deferred**: ask with the customer's first-run (a demo question) |
| 13 | The Google Maps link | Works; sits tight at the top of the job screen | **Deferred** (cosmetic): move beside "ניווט לכתובת" in the shared screen |
