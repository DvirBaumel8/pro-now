acceptance criteria are in `docs/21-PRODUCTION-PLAN.md` W3:

## What was built

- A shared `GeocodingProvider` contract with Nominatim and deterministic
  fixture adapters.
- A serialized Nominatim request queue, Hebrew locale, contact identity,
  malformed-result filtering, and normalized cache keys.
- A 30-day `geocode_cache` table plus public reverse and search endpoints.
- The `/addresses` product screen: browser permission, resolved Hebrew
  address, typed-address fallback, saved addresses, loading/error/offline
  states, and “for someone else” disabled until W6.
- A typed API-client surface for saved addresses and geocoding.

## Acceptance

- Prisma migration deploy and drift check: passed against local PostGIS.
- API integration suite: 57 tests passed.
- W3 browser suite: 4/4 passed in WebKit at iPhone 15 dimensions and
  Chromium, covering permission-granted resolution and denied fallback.
- Full workspace `npm test`, `npm run typecheck`, and `npm run lint`: passed.

The browser suite uses the deterministic fixture provider through the test
web server; the Nominatim adapter is contract-tested with fake fetches, so
CI does not depend on external geocoding availability. A separate physical
iPhone check and live Nominatim smoke test remain deployment follow-ups.
